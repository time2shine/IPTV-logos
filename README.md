# 📺 StreamVault IPTV Channel Logos

Official, high-resolution, transparent broadcast channel logos optimized for [StreamVault IPTV](https://github.com/time2shine/StreamVault-IPTV).

- **Total Logos Hosted:** 1077
- **Matched Live Channels:** 1079 / 1232 (87.6%)
- **Delivery CDN:** Free global high-speed edge caching via [jsDelivr CDN](https://www.jsdelivr.com/)

---

## 🚀 CDN URL Format

Every logo is available over HTTP/2 with permanent SSL and global edge caching:

```text
https://cdn.jsdelivr.net/gh/time2shine/IPTV-logos@main/logos/<channel_name>.png
```

- **FOX Sports (Real Horizontal Transparent):**  
  `https://cdn.jsdelivr.net/gh/time2shine/IPTV-logos@main/logos/fox_sports.png`
